# Политика безопасности (Security Policy)

## Поддерживаемые версии

Мы поддерживаем актуальные версии всех публичных инструментов и SDK экосистемы NormaHub.

| Проект | Поддерживаемые ветки / релизы |
|---|---|
| `@normahub/mcp-server` | >= 0.2.0 |
| `normahub-cli` | >= 1.0.0 |
| `seedance-video-api` | >= 0.2.0 |
| `code-review-action` | v1 (`v1.x.x`) |

## Сообщение об уязвимости

Если вы обнаружили потенциальную уязвимость безопасности в сервисах, API или клиентских библиотеках NormaHub:

1. **Пожалуйста, не создавайте публичный GitHub Issue.**
2. Отправьте отчёт на электронную почту: **security@normahub.cc** или **manager@normahub.cc**.
3. Укажите:
   - Описание найденной проблемы
   - Шаги для воспроизведения
   - Оценку степени критичности
   - Контакты для обратной связи

Мы подтвердим получение сообщения в течение 24 часов и проинформируем вас о ходе устранения.
