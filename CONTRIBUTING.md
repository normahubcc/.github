# Руководство по участию в проектах NormaHub (Contributing)

Мы приветствуем идеи, предложения и Pull Request'ы от разработчиков и пользователей!

## Как внести свой вклад

1. **Создайте Fork** репозитория, в который хотите внести изменения.
2. **Склонируйте форк** локально и создайте отдельную ветку:
   ```bash
   git checkout -b feature/awesome-feature
   ```
3. **Внесите изменения** и проверьте качество кода:
   - Для Node.js/TypeScript: `npm test` и `npm run lint`
   - Для Python: `pytest` и `ruff check .`
4. **Оформите коммиты** в формате Conventional Commits (`feat: ...`, `fix: ...`, `docs: ...`).
5. **Создайте Pull Request** в ветку `main` оригинального репозитория.

## Принципы архитектуры

- **Отказоустойчивость:** Любые сетевые вызовы к API должны содержать разумные таймауты и автоматические повторы при временных сбоях (retry backoff).
- **Минимализм зависимостей:** Мы стараемся минимизировать тяжелые внешние зависимости, используя возможности стандартных библиотек современных версий Node.js (18+) и Python (3.9+).
- **Безопасность данных:** Никогда не добавляйте реальные API-ключи (`nr_hub_...`) в код, тесты или историю коммитов.
